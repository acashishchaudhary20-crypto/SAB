⇪ Bulk Import Existing Files

Bring all your existing project files in one go — from Desktop, Downloads, Google Drive, OneDrive or a pen drive. Each file is copied into the system and filed as a Letter or a Document. Date, letter number, sender, category and document type are read from the file name and the text inside PDFs / Word files, and that text becomes searchable. Files imported before are skipped automatically, so you can run this again any time.

1. Choose the folder on this computer

Click a folder to open it; click Import this folder when you are inside the right one. Sub-folders are included.

If a folder says macOS did not allow access: open System Settings → Privacy & Security → Files & Folders (or Full Disk Access) and switch on Terminal, then restart SAB.

Other way: pick files with the browser window

2. File them as

Result

Open any imported record to correct the details (e.g. mark a letter Reply Required, set Outgoing, fix the subject).
