Or connect one folder at a time (better if a drive also holds personal files — connect only the project folders):

• The first indexing of a large drive can take a while (Google Drive / OneDrive download each file once to read it). Keep SAB running.
• If you see “macOS blocked access”: System Settings → Privacy & Security → Full Disk Access → switch on Terminal, then restart SAB.
• Deleted or moved files are marked missing; their records stay. Scanned PDFs are indexed by name; the Assistant can still read them.
